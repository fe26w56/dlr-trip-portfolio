# 公開版の来歴

`dlr-trip-planner`から、旅程を表示する5つのReactコンポーネントを抽出しました。
ソースの照合情報は[source-manifest.json](source-manifest.json)にあります。
ここに記載したSHAは抽出時のGit treeです。

DayTabs、ProgressBar、NowNextCards、ScheduleList、BottomNavigationの配置と表示を引き継いでいます。
DayTabsには選択状態の読み上げを、ScheduleListにはキーボード操作とボタン名を追加しました。
型定義は公開デモが扱う項目に絞っています。

App、サンプルデータ、詳細ダイアログ、簡易ボタン、待ち時間の表示アダプター、デスクトップ向けの説明欄は公開用に追加しました。
運用版の待ち時間取得処理、地図、認証、同期、写真は含めていません。
公開版の画面全体が運用版と同一であることを示すものではありません。

履歴を引き継がず、新規リポジトリに必要なファイルだけを追加しています。
依存パッケージのライセンスは各パッケージに従います。
